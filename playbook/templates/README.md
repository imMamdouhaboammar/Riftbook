# Playbook Templates

Reusable starting points for adding consistent material to the practical playbook. Use a template only when the new content has a clear place in the existing structure.

## Available templates

- [Lesson template](./lesson-template.md) for instructional playbook lessons
- [Mistake template](./mistake-template.md) for concrete failure and recovery write-ups
- [Story template](./story-template.md) for experience-based lessons
- [Case study template](./case-study-template.md) for evidence-backed project examples
- [Path template](./path-template.md) for guided learning or execution sequences
- [Section README template](./section-readme-template.md) for consistent section indexes
- [Superhero Prompt](./superhero-prompt.md) for the reusable agent-preparation prompt referenced by the getting-started path

## Before creating content

Search the playbook first. Prefer improving an existing lesson, path, story, or mistake entry when the new material would substantially overlap.

When a new page is justified, copy the closest template, replace all instructional placeholders, add it to the appropriate section index, and verify every repository-local link before submitting the change.
