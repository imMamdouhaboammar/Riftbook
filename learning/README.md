# Learning Paths

Structured courses, tutorials, and study resources that help builders understand the concepts behind better AI-assisted apps.

These are not tools to install. They are learning resources to study, practice, and turn into real workflows.

## Start with engineering foundations

If you can already ask a coding agent to build features but struggle to reason about state, data consistency, retries, concurrency, testing, CI, or architecture, start with [Engineering Foundations for AI-Assisted Builders](./engineering-foundations-for-ai-builders.md).

If Git state, branches, commits, recovery, or pull-request review still feel uncertain, start with [Git and GitHub for AI-Assisted Builders](./git-github-for-ai-assisted-builders.md) before asking an agent to ship repository changes autonomously.

## Suggested order

1. Learn Git and GitHub first if you cannot confidently inspect, isolate, review, and recover repository changes.
2. Study Engineering Foundations against a real repository.
3. Complete its end-to-end feature capstone.
4. Use the [Path Finder](../playbook/paths/path-finder.md) to choose the next workflow problem.
5. Study agent-specific architecture when your project actually needs it.
