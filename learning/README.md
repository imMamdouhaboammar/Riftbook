# Learning Paths

Structured courses, tutorials, and study resources that help builders understand the concepts behind better AI-assisted apps.

These are not tools to install. They are learning resources to study, practice, and turn into real workflows.

## Start with engineering foundations

If you can already ask an AI coding agent to build features but struggle to reason about state, data consistency, retries, concurrency, testing, CI, or architecture, start with [Engineering Foundations for AI-Assisted Builders](./engineering-foundations-for-ai-builders.md).

It progresses through 13 connected concepts using real-repository practice tasks instead of isolated definitions.

## Suggested order

1. Learn the software concepts in Engineering Foundations.
2. Apply them to one real feature using the capstone map.
3. Use the [Riftbook Path Finder](../playbook/paths/path-finder.md) to choose the next workflow problem.
4. Study AI agent architecture separately when your project actually needs agent-specific patterns.
