# Learning Paths

Structured courses, tutorials, and study resources that help builders understand the concepts behind better AI-assisted apps.

These are not tools to install. They are learning resources to study, practice, and turn into real workflows.

## Start with engineering foundations

If you can already ask a coding agent to build features but struggle to reason about state, data consistency, retries, concurrency, testing, CI, or architecture, start with [Engineering Foundations for AI-Assisted Builders](./engineering-foundations-for-ai-builders.md).

It connects 13 software-engineering concepts to practical repository inspection exercises.

## Suggested order

1. Study Engineering Foundations against a real repository.
2. Complete its end-to-end feature capstone.
3. Use the [Path Finder](../playbook/paths/path-finder.md) to choose the next workflow problem.
4. Study agent-specific architecture when your project actually needs it.
